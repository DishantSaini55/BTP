# Final manuscript package v1

Overleaf entry point: `main.tex`. The manuscript and figures use the corrected official-test v2 records and verified v3 derivatives. `supporting_data/` contains the canonical metrics CSVs and copied source reports used for reporting. `diagrams/` contains editable SVG, Mermaid, and draw.io sources plus PNG exports. `hive/` is a prospective protocol package only; no participants or responses exist.

The official-test bundle stores per-window scores and identifiers, not prediction coordinates. Thus test trajectory overlays are explicitly not reconstructed; no inference was rerun. The manuscript is a supervisor-review draft and still requires author/institution metadata and human approval for any prospective participant study.
