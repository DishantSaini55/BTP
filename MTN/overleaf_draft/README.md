# IDD-PeD / MTN Overleaf draft

Upload this folder to Overleaf and set `main.tex` as the main document. The editable C4 figure is drawn with TikZ and needs no binary asset.

This draft uses only completed CPU Farneback proof-of-concept (POC) results. It does not claim reproduction of the published RAFT-based IDD-PeD benchmark. Numerical prior-work values are intentionally omitted until they can be verified under a comparable protocol.

## Contents

- `main.tex` -- paper entry point
- `sections/proposed_methodology.tex` -- methodology and contributions
- `sections/experimental_results.tex` -- matched results and comparison boundary
- `sections/ablation_study.tex` -- completed architecture ablations
- `sections/limitations_and_next_steps.tex` -- limitations and scoped next steps
- `figures/c4_architecture.tex` -- editable vector TikZ C4 diagram
- `references.bib` -- verified repository citation placeholder
